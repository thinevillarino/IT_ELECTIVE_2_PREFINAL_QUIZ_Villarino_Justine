## Portfolio Flow

1. Open the application.
2. The Login page will appear first.
3. Enter the demo username and password.
4. After a successful login, the user will be redirected to the Home page.
5. Select **Explore My Projects** or **Projects** to view the project collection.
6. Use the **Prelim, Midterm, and Prefinal** table of contents to navigate through the project categories.
7. Select **View Project** to open the details of a project.
8. Each project detail page contains its description, screenshot, GitHub repository link, and comment section.
9. Select **Logout** to end the current session and return to the Login page.
